## Gotchas / invariants (do not violate)
- **All `.claude/` writes happen in the MAIN loop** — subagents are sandboxed from `.claude/` (DEC-004). Use subagents only for read/search/analysis, not edits.
- **Determinism**: identical output for a fixed `--now`; no `Date.now`/random in emitted HTML (would break the byte-identical test + the `task_hash` freshness model).
- **Reuse the data layer; never regex-scrape the rendered output** (the prototype's `viz.py` sin — independent-eval condition #1).
- **Spec/decisions are LINKED, not embedded** — keeps the file ~25–60 KB + single-source.
- **Drift detection is untouched** (it hashes the spec, not the dashboard) — don't change `fingerprint.py`/`drift-reconciliation.md` for this.
- **Single `spec_v{N}.md` invariant** — untouched.
- Route any *substantive* spec/decision edits through the proper workflow; this work edits `.claude/scripts`, `.claude/rules`, `.claude/support/reference`, `.claude/commands`, `.claude/CLAUDE.md`, `.gitignore`, `version.json`, and root `decisions/`+`template-maintenance/` — all template-owned, edited directly.
